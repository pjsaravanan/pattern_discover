---
name: PRS source of truth
description: The user's project-specific requirement for maintaining one canonical requirements document.
---

The original Product Requirements Specification is the single living source of truth. Record every agreed change, clarification, or deviation in that document rather than scattering requirements across separate documents.

**Why:** The user wants one authoritative reference.

**How to apply:** Update the original PRS with approved decisions before creating plans or implementation work.
